= Requirements

:game-name: 위그드라실
이 문서는 생태 전략 시뮬레이션 게임 {game-name}(Yggdrasill)의 요구사항을 명세한다.

== Constraints
* {game-name}은 Windows와 MaxOS 플랫폼을 지원한다.

== System Requirements

=== 메뉴 씬
* {game-name}은 메뉴 씬으로 시작한다.
* 메뉴 씬에서 QUICK PLAY 버튼을 클릭하면, 대기 시간 후 게임 씬으로 전환된다.

=== 게임 씬
* 게임의 맵은 정사각형 격자 구조이다.
* 플레이어가 격자 칸을 클릭하면, 해당 칸에 묘목이 생성된다.

=== 멀티플레이
* 플레이어가 게임 씬에 진입할 때 매치메이킹 서버에 방이 존재하지 않으면, 새로운 방이 생성된다.
* 플레이어가 게임 씬에 진입할 때 매치메이킹 서버에 방이 존재하면, 해당 방에 입장한다.
* 같은 방에 입장한 플레이어들은 게임 씬의 맵 상태가 동기화된다.
** 묘목의 개수와 위치가 동기화된다.
