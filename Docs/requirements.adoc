= Requirements

:game-name: 위그드라실
이 문서는 생태 전략 시뮬레이션 게임 {game-name}(Yggdrasill)의 요구사항을 명세한다.

== Constraints
* {game-name}은 Windows 플랫폼을 지원한다.

== System Requirements

[[game-version, 게임 버전]]
=== <<game-version>> 
{game-name} 애플리케이션에는 semantic versioning 방식의 버전이 부여된다.

=== 메뉴 씬
* {game-name}은 메뉴 씬으로 시작한다.
* 메뉴 씬은 초기에 다음 두 버튼으로 구성된다.
** 싱글 플레이
** 멀티 플레이

==== 싱글 플레이
* 싱글 플레이 버튼을 클릭하면, <<game-scene>>이 시작되고, 두 명의 로컬 플레이어로 구성된 게임 시뮬레이션이 시작된다.

==== 멀티 플레이
멀티 플레이 버튼을 클릭하면, 다음 세 가지 버튼이 뜬다.

* <<auto-matching>>
* 비공개 방 만들기
* 비공개 방 참가하기
 
멀티 플레이를 위해, 다음 두 가지 방식의 매치메이킹이 지원된다.

* <<auto-matching>>
* <<private-room-matching>>

위 두 방식 모두, 클라이언트 풀 내에서만 매칭이 이루어진다. 클라이언트 풀의 정의는 다음과 같다.
[[client-pool, 클라이언트 풀]]
<<client-pool>>:: <<game-version>> 설정이 일치하는 모든 클라이언트 집합.

[[auto-matching, 자동 매칭]]
===== <<auto-matching>>
* <<auto-matching>> 버튼 클릭 시, <<client-pool>> 내에 매칭 대기 중인 다른 클라이언트가 존재할 때까지 대기한다. 
* <<client-pool>> 내에 매칭 대기 중인 다른 클라이언트가 하나 이상 존재한다면, 그 중 임의의 한 클라이언트와 같은 방에 입장한다.

[[private-room-matching, 비공개 방 매칭]]
===== <<private-room-matching>>
[[invitation-code, 참가 코드]]
* "비공개 방 만들기" 버튼 클릭 시, <<invitation-code>>가 자동 생성되고, <<invitation-code>>가 부여된 비공개 방이 생성된다.
* "비공개 방 참가하기" 버튼에서 <<invitation-code>>를 입력하면, 다음 조건을 모두 만족할 경우 방에 참가한다.
+
. 해당 <<invitation-code>>가 부여된 비공개 방이 존재한다.
. 해당 방에 클라이언트가 하나 뿐이다.
. 해당 클라이언트가 자신과 같은 <<client-pool>>에 있다.
* 위 조건을 만족하는 방을 찾지 못한 경우, 에러 메시지를 띄운다. 에러 메시지에서 OK 버튼을 클릭하면 메뉴 초기 화면으로 돌아간다.

===== 멀티플레이 동기화
* 같은 방에 입장한 플레이어들은 <<game-scene>>의 맵 상태가 동기화된다.
** 묘목의 개수와 위치가 동기화된다.

[[game-scene, 게임 씬]]
=== <<game-scene>>
* 게임의 맵은 정사각형 격자 구조이다.
* 플레이어가 격자 칸을 클릭하면, 해당 칸에 묘목이 생성된다.
